# 引用核对

引用需要分别解决三件事：文献是否存在、题录与正文引用是否对应、文献内容是否支持具体论述。只有 DOI／PMID 或题录匹配不能证明文章支持某个观点；摘要、全文以及用户自带资料的阅读范围要分开记录。未获取全文时不要声称读过全文，无法核实的引用标待核，不捏造题录、出处或文献观点。

可使用随包的 `scripts/ye1_reference_audit.py` 对公开参考文献题录做辅助核对。先在本地单独整理参考文献列表，不把患者数据、未发表稿件正文或私人信息作为检索词。支持 BibTeX、含 `title`、`year`、`doi`、`pmid` 等表头的 CSV／TSV，以及每行一条的纯文本或 Markdown 列表；也可读取 Word 中标题明确的参考文献节（需要 python-docx）。纯文本和 Word 仅提取 DOI 和明确标注的 PMID，不自动解析题名；Word 只处理识别到的参考文献节，未能识别时另存参考文献列表。网络查询只发送识别到的 DOI／PMID，分别访问 Crossref 和 PubMed；`--offline` 不联网。

```sh
python scripts/ye1_reference_audit.py references.bib --out 任务工作目录/reference-audit.json
```

输出路径必须为新文件，不覆盖已有成果。逐项核对提取条目数量；无标识、查询失败和离线条目均为 `UNVERIFIED`，`IDENTIFIER_FOUND` 仅表示对应数据库返回题录，不等于引用内容正确；题名、年份或 DOI 发现差异时会提示人工复核。DOI／PMID 未能核实可能是数据库收录范围、网络或格式问题，不据此判断造假。若 BibTeX 或表格里只有题名，先确认该列表只含公开文献信息，再使用 `--allow-title-lookup` 查询 Crossref；题名查询只返回候选，不代表已核实，须结合作者、年份及原文人工判断。纯文本不会自动解析题名。工具默认不上传题名或稿件正文。年份不同时注意在线发表和正式出版时间可能不同。撤稿和更正状态需另查数据库及出版社公告，不由此脚本保证。

对于承载核心论证、方法或重要数字的引用，应阅读实际可取得的原文或摘要，判断研究对象、方向、结果及局限是否与所写内容对应；来源不能支持的句子应修改或保留待核，不能用看似相似的文献替换成事实。发表年份、撤稿及更正状态按实际题录和公告核实，不凭 PMID 数字范围推定；离线无法核实就标待核。

需要旧工具支持的特殊格式、OpenAlex 回退或进一步解析时，可按需使用原 `scripts/verify_refs.py`；默认只按标识查询，题名查询必须在已确认列表仅含公开文献时单独启用。两个工具的能力和结果范围不同，应分别检查。
