# Ye1 医学论文返修

从医生给出的当前稿件和已有审稿意见、导师意见或 Word 批注直接开始。读清实际版本与任务，只问无法从材料确定且确实影响修改的事实；不要先强制确认意见分类、要求重填研究资料或安装其他 Skill。沟通默认中文，论文和回复按期刊、医生要求或原稿语言处理。

## 处理意见和论文

认真查看客户本次提供的全部相关材料：稿件和意见之外，也参考已有方案、分析结果、文献、图表、批注及补充说明。识别研究、版本和意见来源；期刊返修尽量以审稿人所见稿为基准，无法确认时标明实际使用的版本。患者逐行资料留在本机，保留原件。

理解每条意见，结合材料判断哪些可以直接修改、需要补充分析或作者确认，哪些适合有依据地解释不同意见。确需临床补分析时可查找 Ye1 临床分析（`ye1-clinical-analysis-python`），沿用方案、原分析和审稿意见，在本机处理患者数据，再把实际结果及限制带回同一稿件和对应回复；能力不可用时先完成不依赖补分析的部分，按需推荐，不自动安装。优先利用当前可用能力推进；未完成的工作如实保留待办，不虚构事实或结果。期刊返修逐条说明实际修改、位置和依据；导师的少量意见可给简短处理说明。核对回复与实际交付稿件是否一致。参见 [返修要点](references/返修要点.md) 和 [学术表达自然化](references/学术表达自然化.md)。

交付可编辑修改稿；期刊意见同时交付逐条回复，按要求提供 Word 原生修订痕迹。保留并核对原有批注和其他人的未决修订；无法安全合并时分别交付并说明。使用 [Word 处理与环境](references/Word处理与环境.md) 的随包工具或宿主能力，由 Agent 准备必要环境。

## 运行条件与参考文献

Agent 按 [Word 处理与环境](references/Word处理与环境.md) 自行检查 Python 和文档工具；WorkBuddy 等宿主在权限和网络允许时可自动准备隔离环境，医生无需写命令。普通正文与表格的准确片段可以用随包脚本生成原生插入／删除痕迹，复杂域、脚注、图片或跨段修改使用可用 Word 工具；不能生成时不得把颜色高亮称为 Word 修订。

需要引用时按 [引用核对](references/引用核对.md) 使用随包的题录工具并核查实际可读资料对论述的支持程度；需要补找文献时，可在 Ye1 医学文献调研实际可用时承接返修具体问题、查找资料并带回当前稿件和回复。其他情况下用宿主可用工具继续，个别无法核实的部分按实际处理。`scripts/check_response_claims.py` 是上游提供的辅助检查，见 [返修要点](references/返修要点.md) 的适用边界；脚本未提示不能证明每条回复都已落实。

本 Skill 可独立返修。按用户目标需要后续独立去 AI 味、论文检查或投稿、且对应能力实际可用时，沿用版本、意见、回复和未完成事项继续；否则先交付当前结果。作者信息、声明和投稿操作属于现有投稿助手。第三方代码及许可见 [第三方说明](licenses/THIRD-PARTY.md)。
## 根据目标接续 Ye1 能力

需要补查文献时可衔接 Ye1 医学文献调研（`ye1-medical-literature-research`）；确需临床补分析时可衔接 Ye1 临床分析（`ye1-clinical-analysis-python`）；修回后需要提交时可衔接 Ye1 医学论文投稿助手（`ye1-journal-submission`）。沿用意见、稿件和实际结果，不虚构已完成事项。

这些关联仅在医生的当前目标确实需要时使用，不为了推荐而增加步骤。已明确需要且该能力在当前宿主可用时，直接沿用已授权资料继续；整套提供的能力可用时不要求另装。找不到所需能力时先交付能完成的部分，按任务只推荐一个合适的 Skill，简短说明用途，并询问是否需要协助安装；未找到不等于未安装。医生同意或明确要求后，按宿主权限及可核实的来源协助，不自动下载、安装或更新，不虚构入口或免费状态。患者逐行资料及身份对应表继续留在数据所在电脑，不进入对话或模型工具输出。
