# Ye1 医学论文返修

**围绕审稿意见修改稿件，整理逐条回复。**

- 读取编辑、审稿人、导师或合作者意见及已有 Word 批注。
- 结合稿件和研究材料处理意见，生成修改稿和期刊返修逐条回复。
- 按需提供 Word 原生修订痕迹；需要补充的分析和作者决定如实标注。

试着说：“请根据审稿意见修改这篇论文，并准备逐条回复。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-paper-revision-skill.zip)，解压后保留完整的 `ye1-paper-revision` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-paper-revision` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-paper-revision/SKILL.md)。
